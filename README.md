# QA_UNSUP_CHECK

Экспериментальный репозиторий для подготовки, проверки и сравнения обучающих корпусов в задаче автоматизированной русскоязычной интерпретации кариотипов в нотации ISCN.

Проект является частью дипломной работы **«AI-генетический консультант»**. Основная задача этого репозитория — проверить, насколько специализированный instruction-based корпус формата `ISCN → Q&A-интерпретация` эффективнее общего медицинского корпуса при дообучении LLM.

> ⚠️ Репозиторий предназначен для исследовательских экспериментов. Результаты генерации не являются медицинским заключением и требуют проверки специалистом.

---

## Контекст проекта

В клиниках вспомогательных репродуктивных технологий (ВРТ) результаты кариотипирования фиксируются в формальной нотации ISCN. Такая запись компактна, но требует экспертной интерпретации: необходимо разобрать число хромосом, половые хромосомы, тип аномалии, вовлечённые хромосомы, точки разрыва и возможное клиническое значение.

В рамках общей архитектуры проекта исследуются следующие подходы:

- rule-based парсинг ISCN;
- BioBERT / biomedical NLP для обработки типовых ошибок;
- baseline LLM без адаптации;
- RAG с внешней базой знаний;
- full fine-tuning;
- LoRA-адаптация LLaMA-3.1-8B-Instruct;
- production-инференс через vLLM и FastAPI.

Данный репозиторий относится к блоку **подготовки корпуса, запуска экспериментов и расчёта метрик**.

## Цели репозитория

1. Сформировать и проверить датасеты для обучения LLM на задаче `ISCN → русскоязычная интерпретация`.
2. Сравнить неспециализированный медицинский корпус (`UNSUP`) и специализированный `ISCN Q&A`-корпус.
3. Запустить LoRA и full fine-tuning эксперименты на сопоставимых данных.
4. Рассчитать автоматические и производственные метрики:
   - BLEU;
   - BERTScore F1;
   - Perplexity;
   - Exact Match;
   - latency;
   - tokens/sec;
   - tokens/joule, если доступна телеметрия GPU.
5. Сохранять результаты в табличном виде для последующего анализа.

## Основная идея эксперимента

Сравниваются два типа обучающих данных:

| Корпус | Назначение |
|---|---|
| `UNSUP` / общий медицинский корпус | Контрольный корпус по медицинской генетике без строгого формата ISCN Q&A |
| `QA` / специализированный ISCN Q&A-корпус | Instruction-based пары: вопрос с ISCN-записью и эталонная русскоязычная интерпретация |

Гипотеза: специализированный Q&A-корпус должен давать более управляемые и клинически корректные ответы, чем общий медицинский корпус сопоставимого объёма.

## Ключевые результаты из дипломного исследования

В отчёте по проекту сравнение fine-tuning на общем медицинском корпусе и специализированном ISCN Q&A-корпусе показало существенное преимущество Q&A-данных:

| Корпус | Метод | BLEU, % | BERTScore F1, % | Clinical correctness / Expert score, % |
|---|---:|---:|---:|---:|
| Общий медицинский корпус (`UNSUP`) | FFT | 0.23 | 13.46 | 6.86 |
| Специализированный `ISCN Q&A` | FFT | 19.80 | 35.16 | 59.81 |


Вывод: специализированные instruction-based Q&A-данные и LoRA-адаптация дают лучший баланс качества и производительности.

## Установка окружения

Рекомендуется использовать Python 3.10+ и отдельное виртуальное окружение.

```bash
python -m venv .venv
source .venv/bin/activate

pip install --upgrade pip
pip install torch transformers datasets accelerate peft bitsandbytes
pip install pandas numpy openpyxl scikit-learn tqdm nltk bert-score rouge-score
pip install sentence-transformers faiss-cpu jupyter
```

Для GPU-экспериментов установите версию PyTorch, совместимую с вашей CUDA.
